# MOYO Product Catalog

A responsive product catalog layout based on a MOYO e-commerce design.

The project focuses on semantic HTML, reusable BEM components, SCSS architecture, responsive CSS Grid, and smooth UI interactions.

## 🔗 Live Demo

[View Live Demo](https://aamaltseva-sqwosh.github.io/layout_catalog/)

## 🎨 Design

The layout was implemented based on a provided Figma mockup of the MOYO product catalog.

## 🛠 Technologies

* HTML5
* SCSS
* BEM methodology
* CSS Grid
* Responsive Design
* Git & GitHub

## ✨ Features

* Responsive product catalog
* Semantic HTML structure
* Reusable Header, Stars, and Product Card components
* BEM naming methodology
* SCSS variables and reusable styles
* Responsive CSS Grid layout
* 1-column layout on small screens
* 2 columns from 488px
* 3 columns from 768px
* 4 columns from 1024px
* Product card hover animations
* Navigation hover states
* Interactive Buy buttons
* Smooth transitions and UI effects

## 📱 Responsive Layout

The catalog automatically changes the number of product columns depending on the screen width:

* 1 column — mobile
* 2 columns — from 488px
* 3 columns — from 768px
* 4 columns — from 1024px

This allows the catalog to remain readable and consistent across different devices.

## 🎯 UI Details

The interface includes:

* Product image
* Product title
* Product code
* Rating
* Review count
* Price
* Buy button
* Category navigation

Product cards use smooth hover animations without affecting neighboring elements in the grid.

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/aamaltseva-sqwosh/layout_catalog.git
```

2. Go to the project directory:

```bash
cd layout_catalog
```

3. Install dependencies:

```bash
npm install
```

4. Start the project locally:

```bash
npm start
```
